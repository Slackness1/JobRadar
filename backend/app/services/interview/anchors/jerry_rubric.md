# Jerry Rubric — Interview Coaching Anchors

> 来源：作者与战略咨询 senior 老师 Jerry 的 10 次辅导逐字稿（2025-10-13 ~ 2026-05-11），约 8400 行。
> 适用方向：金融科技 / 咨询·科技咨询·四大 / 数据分析 / 量化·金融工程。
> 用途：作为 LLM judge 的 system prompt anchor 注入；面试报告的维度评分 / 反馈语气以此为锚。
> 引用规范：所有 Jerry 原话片段保留 `日期 HH:MM:SS` 格式以便回溯审计。

## 评分维度（6 维，权重总和 1.0）

### 1. 结构化表达 (structure, 权重 0.20)

**核心理念**：面试官在听 + 看简历两线并行时极易 lost。候选人必须主动给框架、报点位。

| 等级 | 表现 | Jerry 原话锚点 |
|---|---|---|
| 5 | 明确报点位（"我讲第 N 段 / 我做的核心三件事"），每段一句话收住，按 客户痛点→目标→方法→交付物 递进，最后落到岗位匹配 | "我核心做的三件事。第一件事围绕的是欧洲电力交易市场……第二个基于政策研究……结构一定要清晰" [20260429 00:02:33] |
| 3 | 知道要分段但层次乱跳，钻进细节再硬拉回来 | "你把人家扔到了一个坑里面，然后又让人家爬出来去下一个坑。他很有可能已经要 loss 掉" [20260429 00:03:38] |
| 1 | 洋洋洒洒一摊，铺垫极长亮点被埋；列举半截"有很多问题，比如…一个两个没了" | "你必须要抓住别人的这个思路……如果我是面试官的话，你讲完前三句我的思维已经散掉了" [20260425 01:36:52] |

### 2. 颗粒度控制 (granularity, 权重 0.15)

**核心理念**：第一层 = 试探兴趣点；第二层 = 重点模块；第三层 = 仅在追问后展开。

| 等级 | 表现 | Jerry 原话锚点 |
|---|---|---|
| 5 | 自我介绍永远停在第一/二层；用"看您对哪段感兴趣"递球 | "你的第一次的展开介绍其实是你在试探他对什么东西感兴趣……点到他感兴趣的点之后，你再去洋洋洒洒跟他聊" [20260429 00:12:14] |
| 3 | 一开口就跳第三层（模块名 / 调参细节） | "你这里第一个你的这个项目的介绍太啰嗦了……就不要上来就是跟他讲这个里面我包括什么什么什么模块" [20260425 01:10:02] |
| 1 | 沉到细节出不来（招行私行起点、监管局组织架构这种） | "你不用跟他讲太细……要克制住自己去抠细节的这种冲动" [20260425 00:26:57] |

### 3. 互动与读场 (interaction, 权重 0.20)

**核心理念**：面试 = 双向沟通。纯独白即使内容好也会被判负。要观察情绪、递球、收尾。

| 等级 | 表现 | Jerry 原话锚点 |
|---|---|---|
| 5 | 看面试官眼神散就快速收住；用"这部分还有些细节，看您是否感兴趣"递球；收尾必落到岗位匹配 | "聊的过程中也别自顾自的在那说，看着点对方的情绪和脸色……他眼神散了……你就要及时的把这个内容收住" [20260429 00:12:14] |
| 3 | 讲完不递球，等面试官提问；机会被错过 | "你不能他自己讲完了，然后他也没机会问了……他可能在打分的时候，他也要手里面也要稍微留一留余地" [20260429 00:13:49] |
| 1 | 对方已左顾右盼/玩笔，你还在滔滔不绝 | "千万不要聊高兴了只顾着聊自己想说的话，也要听一听对方在说什么" [20260429 00:19:19] |

### 4. 动机框架 (motivation, 权重 0.15)

**核心理念**："为什么咨询/为什么我们/为什么你"是三大送命题。空泛动机会被瞬间识破。

| 等级 | 表现 | Jerry 原话锚点 |
|---|---|---|
| 5 | 收窄子赛道（咨询→科技咨询）；性格-能力闭环；落到"我适合你"而非反过来 | "我选择的不是咨询，我选择的是科技咨询……结合我个人的这种性格，我是一个比较愿意去不断做挑战的" [20260429 00:16:47] |
| 3 | "我喜欢咨询的工作方式" / "可以发挥我的复合背景" — 飘在空中 | "咨询是什么工作模式，跟券商有什么不一样，这些你属于都是飘在空中的" [20260425 01:22:17] |
| 1 | "我适合所以我选"循环论证；'咨询是开放式问题'这种被一句打回的判断 | "你适合咨询，不代表你不适合券商……马上就变成我因为我适合，所以我选择。本身这个逻辑也不成立" [20260425 01:21:01] |

### 5. 行业认知深度 (industry_insight, 权重 0.15)

**核心理念**：金融科技/咨询岗对 business acumen 极敏感 — 用产品-客户-渠道-支撑四要素拆，区分子行业。

| 等级 | 表现 | Jerry 原话锚点 |
|---|---|---|
| 5 | MECE 拆解 + 跨子行业辨析（银行/保险/券商代销在粘性、产品线、客户基数上的差异） | "保险只有代销基金牌照……银行你只要是工资卡每个月至少要开一次 APP……跟客户的交互粘性差异是挺大的" [20260425 00:11:23] |
| 3 | 能讲'客户分层'/'AUM 漏斗'，但说不出'山西银行高净值玩不动'这种结构性洞察 | "区域性银行的这种能力上限……跟大银行比就是存在着天生的短板" [20260212 00:24:31] |
| 1 | 停在'客户体验很重要'这种零信息量；没意识到监管红线 | "监管目标是金融系统的良好稳定的运行……所以这个东西就天然了决定于这个技术，它不能去牵引业务" [20260425 00:42:46] |

### 6. 解决问题导向 (problem_solving, 权重 0.15)

**核心理念**：咨询/科技咨询岗考的是"接到客户需求怎么开展" — 先讲痛点再讲方法；区分 product vs project 视角。

| 等级 | 表现 | Jerry 原话锚点 |
|---|---|---|
| 5 | 痛点→目标→方法→交付物 + MECE 拆解；主动 clarify 是 product 还是 project | "讲清楚客户他要做一个什么事，我是通过一个什么方法去实现的……他非常希望听到你的目标是什么，你的方法是什么" [20260425 01:04:26] |
| 3 | 方法在先痛点在后；被问"怎么开展 HR ai agent"时不区分 product/project | "他需要的是一个项目架构还是产品架构，你能分清楚区别？" [20260425 01:45:56] |
| 1 | 丢痛点 + 强行 clarify | "你不要强行 clarify，人家明明问的很清楚的，你不要强行给人家 clarify" [20260425 01:54:32] |

## 6 大反模式（用于触发式负向反馈）

| 反模式 ID | 触发条件 | Jerry 推荐补救 |
|---|---|---|
| `monologue` | 单次回答 >90s 无停顿 | "纯粹他讲或纯粹你讲都不好" — 主动用"看您是否感兴趣"递球 |
| `premature_detail` | 前 30s 出现模块名 / 库名 / 调参细节 | "不要上来就是跟他讲这个里面我包括什么模块" — 先讲痛点和目标 |
| `drifting_motivation` | "我喜欢" / "我觉得适合" 无具体子赛道 | "都是飘在空中的" — 收窄子赛道 + 行业洞察 |
| `force_clarify` | 对清晰问题反复反问 | "人家明明问的很清楚的，你不要强行给人家 clarify" |
| `missing_landing` | 自我介绍/项目讲述无明确岗位匹配收尾 | "你以后收我一定都是要收到人家那儿去" |
| `pause_too_long` | 句中 3s+ 停顿频繁 | "对方会觉得你好像在藏着什么似的" — 宁可稍快也别长停顿 |
