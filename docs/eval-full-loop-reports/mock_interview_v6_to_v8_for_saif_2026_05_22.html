评分维度从 5 维 → 6 维 (STAR-M 表达深度)

每道题独立打 6 个维度, 不再只给一个总分. SAIF 老师可以直接看出学生在哪一项失分.

岗位能力匹配度

候选人讲的经历 / 技能能直接对得上目标岗位要的能力, 还是只是"沾边".

信息选取与侧重

答的是 hiring manager 真正关心的, 还是答非所问 / 流水账 / 头重脚轻.

逻辑性

痛点 → 目标 → 方法 → 取舍 → 结果 这条链有没有断 / 跳跃 / 颠倒因果.

行业感

用的是行业 insider 才会用的语言 / 数据 / 框架, 还是 common-sense / 媒体口径.

可信度

讲的数字 / 公司 / deal 在简历里能锚到吗? 量级 / 单位 / 时间 / 角色站得住吗?

表达深度

候选人讲一段经历, 是流水账 / 有结论 / 还是有方法论推导 + 验证 — 用 STAR-M 五段衡量 (Situation / Task / Action / Result / Method 方法论).

5 个反"AI 给水分"的守卫机制

SAIF 老师最不希望看到的就是 AI 给虚高反馈. v8 系统加了 5 道闸, 每道都有真实学生案例覆盖.

编造数字守卫 已生效

候选人答里出现简历里没有的"结果型数字" (像"实习生 own 80 亿欧元并购"), 自动扣可信度. 区分"市场公开价格 (茅台 2700 块)" 和"自我编造大数字".

效果: 强档 P8 编 PVSyst 100 万欧元被抓到, 可信度自动扣到 30.

退回 mentor 守卫 v8 N=3 100%

候选人 ≥2 次说"我们 PM 觉得"、"mentor 给的框架"、"组里讨论形成共识", 自动 cap 总分 ≤65, 移除 "内驱力" trait, 反馈末尾追加显式警告.

效果: 红线 P-fake-S1 在 N=3 三次全部触发, 最高分 65 (硬上限).

银行术语白名单 已生效

"协同杠杆"、"task force"、"RFM"、"CRM" 这类正常 banking/consulting 术语不算翻译腔. 翻译腔触发阈值从"出现 1 次"提到"出现 2 次", 防强档误杀.

效果: M13 强档银行从 58 分回到 69-88 真实水平.

反馈生成失败透明化 已生效

AI 报告 LLM 偶发失败时 (~3%), 不再伪造 "6 维全 60 + 看似正常的评语", 改成显式黄色 banner "反馈生成中断 — 请刷新".

效果: 学生区分得清 "系统坏了" 和 "我真 60", 不再被误导.

答题评分失败自动重试 已生效

单题打分时 LLM 调用失败, 自动重试 1 次. 若仍失败, 不让该题污染整场综合分.

效果: 单题 None 数从 v6 的 5 个降到 v8 的 2 个 (基本消除).

额外: 评分浮动透明提示 新

每份反馈卡底部加一行小灰字 + 鼠标悬停说明: "评分含 ±5 分主观波动属正常, 请参考分数区间而非单个数字". 学生不会因为这次 86 / 下次 91 而疑惑.

效果: 跟真实老师评分行为一致 (老师给同一份答卷 3 次也会差 ±3-5 分).

方法学反思 — Day 10 翻车与 Day 11 修法

⚠️ 上一次 (5 月 21) v6 ship 后被独立审查打脸

我用单次跑结果当 ship 依据, 报告里写 "强档平均 80.2 分, P8 87 P9 88" — 看上去全过. 独立审查复测发现 13/27 学生跨 run 漂移 ≥ 10 分, 红线 P-fake-S1 在不同次跑分别给 59、78、82 分 — 同一个学生评分相差 23 分, 我那个"提升 13 分"大概率有一半是 LLM 评分的随机噪声.

核心错误: 把 一次随机 LLM 评分 当成"系统提升了 X 分"的硬证据, 反过来报喜给 SAIF.

Day 11 改造方法学 — 4 条永久规则

M1

N=3 重测才算数

任何 eval-driven 改动 ship 前必须跑 3 次取均值 + 方差, 不能用单次结果当 ship gate. stdev > 5 时只能说 "未发现稳定差异".

M2

红线学生用"期待区间"判

每个 stress 学生 (像 P-fake-S1) 提前定好"期待评分区间" (例如 P-fake ∈ [50,65]), 不只看"比上次高/低", 同时看"是否还在该区间".

M3

独立 subagent 审查抓 ordering bug

我自己写完 v7 修法后, 调一个独立 AI 重审, 抓到我自己漏的 1 个 bug — "trait 抑制写在 trait 生成之前, 是 dead code". 修后红线学生的"内驱力 trait" 真的被 drop 了.

11 个 sentinel 学生 N=3 实测

每个 sentinel 跑 3 次取 mean ± stdev, 看真实方差水平. v8 部分 sentinel 仍有 stdev > 5, 是 LLM scoring 本身的固有方差 (不是 bug), 跟真实老师评同一份答卷 3 次差 ±3-5 分一致.
