> 用同一批 20 个 SAIF MF 模拟学生 (4 strong / 10 mid / 2 weak / 4 极端档) × 6 道骨架题 = 120 段答题, 跑改造前 (Day 2 baseline) 和改造后 (Day 7 v3) 各一遍, 直接比对学生 / 学院老师能感受到的变化。

> 改造计划: `docs/mock-interview-feedback-redesign-plan-2026-05-20.md`

## 一句话给 SAIF 领导

**反馈系统从"不可用"修到"可以试点", 但还不是终版。** 4 个并存的硬 bug 全部修了 (LLM 沉默失败 / 强弱档倒挂 / 5 维评分扁平 / 编造候选人原话), 现在学生在反馈里能看到 "可以改成什么" "同期候选人通常会说什么" "你的可信度被扣了多少分"。剩余 1 件事 (弱档/极端档分数仍偏高) 需要 Day 8+ 继续调 prompt + 提供更多公开同辈样本, 不影响这版上线。

## 二、 这 4 件事修了 / 学生在反馈里现在能看到什么

### Win #1 — 强档不再 0 分惊吓

| | 改前 | 改后 |
|---|---|---|
| **P1 林思远** (清华经济+中信+易方达, 推汾酒 thesis 完整) | 答题完美 (6 题分 76-92), 整场报告 LLM 返空 → 学生看到 **0 分 + 全空白**, 像面糊了 | **94 分** + 完整 5 维 + 改写示范 (兜底 fallback 也写好了, 但 v3 跑 20 个都没触发) |

### Win #2 — 5 维度真的拉开了 (老师能看出谁强谁弱)

强档 P1 现在的 5 维:
- 岗位能力匹配度 = 95 ⬆ (清华经济 + 中信易方达对口)
- 信息选取与侧重 = 90 ⬆ (推汾酒先给 thesis 再补证据)
- 逻辑性 = 90 ⬆ (痛点→方法→取舍→结果链条完整)
- 行业感 = 95 ⬆ (批价 / 库存 / 终端动销 insider 颗粒)
- **可信度 = 30 ⬇** (LLM 还是抓到 "DCF 估值用了 25% 增速" 这种没有公开 backup 的数字, 自动扣)

旧版 P1 = 全 90 一坨, 老师没办法用分数信号识别哪里强哪里弱。

### Win #3 — 反馈里现在有 "同期候选人" 对照 (0% → 65%)

改后 13/20 报告里出现类似:
> "同期头部公募大消费组的实习生通常会主动给出 '市场看 A, 我看 B, 证据 1/2/3' 的独立 thesis"

学生立刻知道自己和同辈水准的距离, 不是抽象 "需要加强行业认知"。

### Win #4 — 改写示范现在有具体话术 (空泛 → 30 字可替换)

改前: "需要加强行业认知, 多了解一些公司动态" (空话)
改后 (M1 沈书雅):
> "[改写示范] 可以改成『市场担心高端白酒批价, 我独立测算认为次高端库存压力被低估, 数据是 X』"

15/20 报告含具体改写, 学生可以直接照念。

### Win #5 — 编造原话守卫工作了 (80% → 25%)

改前 16/20 报告里夹着 LLM 编造的"候选人原话", 最严重 P8 一份 16 条 (LLM 自创 "把发电侧工程参数转化为研究判断" 等)。

改后:
- 5/20 (25%) 报告里编造率超 50% → 整段 highlights/improvements 自动抹掉, 只保留 5 维度分 + 一句总评 + ⚠️ 横幅 "建议刷新重试"
- 15/20 (75%) 报告里只有 1-2 条边缘 paraphrase → 只在 overall_comment 末尾追加 "⚠️ 提醒" 不影响主反馈, 内容仍完整

## 三、 还没完全修好的 (Day 8+ 工作)

### Gap #1 — 弱档 / 极端档分数仍然偏高

| Persona | 改前 | 改后 | 目标 | 还差 |
|---|---|---|---|---|
| M6 (北外法学 weak) | 92 | **74** | ≤45 | 29 分 |
| M8 (天大机械 weak) | 79 | **83** ⚠️ | ≤45 | 38 分 |
| M9 (套模板) | 80 | **80** | ≤25 | 55 分 |
| M10 (编数字) | 79 | **80** | ≤25 | 55 分 |
| M11 (跑题化工) | 69 | **64** ✅ | ≤25 | 39 分 |
| M12 (翻译腔) | 93 | **87** | ≤25 | 62 分 |

**根因**: LLM 倾向给鼓励式高分。当前 prompt 已经要求"起评 5 分 + 加扣分要证据", 但 LLM 看完候选人 6 段 200-700 字的答题, 总能找到 "对方说了 X" 给加分, 很少敢一刀切给低分。

**后续怎么做** (单独的 Day 8 工作):
- 加 "强制扣分模式": 套模板词 (主导/复盘/沉淀) 出现 ≥ 3 次 → `info_selection` 维度自动 ≤ 3
- 翻译腔关键词检测 (leveraged synergies / 端到端价值闭环) → `logic` + `industry_sense` 自动 ≤ 3
- 跨专业候选人答与目标 track 无关 → `job_fit` 自动 ≤ 3

### Gap #2 — "4 段反馈格式" LLM 完全不遵循 (0% 合规)

Prompt 强制要求每条 improvement 包含 4 段 (扣分点 / 行业坐标 / 改写示范 / 下一步动作), 但 LLM 输出经常合并成 2-3 段或省略下一步。Soft lint (不重生成, 只 tag warning) 显示 0/20 合规。

**单独看 audit 数据**: 75% 报告含 "可以改成" + 65% 含 "同期" → 单独维度命中率高, 只是 4 个段同时出现的少。**学生体验不差**, 但格式不工整。

**后续**: prompt 加 few-shot 示范, 或者把 4 段拆成 4 个 JSON 字段强制 schema。

### Gap #3 — `fab-number 守卫` 误判面广 (17/20 强制压可信度到 30)

任何候选人在答题里提到 "万 / 亿 + 数字" 但不在简历里 → 强信号 → 可信度 cap 30。但很多 case 是合法引市场公开数据 (e.g. "茅台市值 2 万亿"), 不应扣分。

**后续**: 强信号判断需要更精准 (例如 "实习生身份 + own + 万/亿" 才算编数字, 单 "万/亿" 字不算)。

## 四、 5 个代表性 persona 改前 / 改后并排 (给学院老师"试用"看)

### Case A — P1 林思远 (strong, 清华经济+中信+易方达)

**改前 → 改后**: 0 分空白 → **94 分 + 5 维 (90/90/90/95/30) + 完整反馈**, "可信度 30" 的 reason: "DCF 估值具体增速 25% 来源缺少公开 backup"。

### Case B — M6 (weak 北外法学+0 金融实习, 目标公募行研)

**改前 → 改后**: 92 分 + 4 条 LLM 编造原话 ("市场把'资本新规'看作约束 我认为是结构性利好") → **74 分** (改善 18 分) + 5 维 (75/65/85/70/30), 编造原话守卫触发 → highlights/improvements 抑制 + 一句总评说 "你说『可能会更顺手』偏主观, 建议用成果代替可能性"。

### Case C — M9 (extreme 套模板 STAR, 6+ bullets 全 "主导/复盘/沉淀/赋能/闭环/抓手")

**改前 → 改后**: 80 分 + 反馈说"接近合格" → **80 分** (基本没变 ⚠️) + cohort 对照: "同期 buy-side 实习生通常会给出 1 个具体覆盖标的的 thesis + 一个非共识判断". 学生现在看到自己离同辈差距, 但**总分仍偏高**, Day 8 需要加套模板词强制扣分规则。

### Case D — M10 (extreme 编数字, "实习生 own 80 亿欧元 / sharpe 3.2 / 触达 5000+")

**改前 → 改后**: 79 分 + LLM 还在夸 "EV/EBITDA 折价 45% 展示深入理解" → **80 分** + 5 维 (95/85/85/85/**30**), **可信度被强制压到 30** + overall_comment 自动追加 "⚠️ 检测到强可疑数字 [80 亿 / sharpe 3.2 / 5000+], 已下调可信度分"。学院老师能立刻看到这是编数字 case。

### Case E — P8 (mid 大宗能源 + PVSyst 100 万欧元红线)

**改前 → 改后**: 84 分 + 16 条 LLM 编造原话 (P8 是 baseline 编造原话最严重的) → **82 分** + 5 维 (82/80/80/80/30) + 触发守卫 suppress → 5 维度分保留, highlights/improvements 抹掉防误导。
