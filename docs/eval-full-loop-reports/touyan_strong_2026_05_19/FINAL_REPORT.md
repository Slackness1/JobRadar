### 高光时刻

实话:**几乎没有真正配得上"高光"的时刻**。勉强举出 3 条偏正面的:

1. **turn 9(follow-up of skeleton Q3)** — 接住了候选人 turn 8 末尾自爆的"我没有真实经历过持续下跌"的钩子,改成假设题"汾酒连续两季批价倒挂你跟踪什么指标"。**接钩的反应是有的**,但选了"出假设题"而不是"那你跟踪期内最大回撤的票是哪只、那段时间 mentor 复盘怎么说的"——后者才是直接撬开 persona blind_spot #2(周期阅历)的问法,前者只是把候选人拽回她最舒适的"框架展示"区。
2. **turn 17** — "你用什么具体量化指标(持仓权重变化幅度、与批价指数的相关系数)支撑这个吻合的结论" 这一题确实把候选人逼到了**整场最低分 55**;候选人不得不承认"吻合是定性描述,没做相关系数"。**这是全场唯一一次让强候选人露怯的题**,值得记一笔。但要批评的是:这一题暴露的是**口述精度问题**,不是 conviction 问题——首席不会因为这个 fail 一个 perfect-resume 强候选人。
3. **turn 19** — 问"和 mentor 有最明显分歧的一次"的样本,候选人交出了"汾酒七月份方向判断 / mentor 说样本太小 / 最终采纳 mentor"。**这是全场离 persona 真盲点最近的一题**,候选人答案也暴露了"分歧不大、最终 mentor 更审慎"——这正是 persona 写的"边角微调,无真实样本"。但产品**没有接住**:这里应该立刻第 4 层追问"那除了这一次,你 8 个月里有没有 mentor 一开始 disagree、最后被你说服的样本",候选人 100% 答不出。产品却切回了 skeleton Q6"你想反过来问什么"——白白浪费了全场最有价值的撬点。

### 暴露问题

1. **skeleton 不分 tier — 强候选人和中等候选人拿到同一套 6 题**。这是结构性缺陷。强候选人的简历 perfect match 的瞬间,产品就应该把骨架第 2 题(主导项目痛点 / 方法 / 目标)替换成"讲一个你 own 的非共识观点 — 谁先提出来的、谁反对过你、最终对错";第 3 题(关键取舍)替换成"你跟踪过的票里最大回撤是多少、当时你怎么向 PM 解释"。现在这套骨架本质是给"中等候选人测下限"用的,**对一个简历无瑕疵的人用同一套题 = 主动放水**。

2. **15 个 follow-up 集中度严重失衡 — 13/15 在打工程方法论,2/15 触碰人 / 决策权 / conviction**。Turn 1/2/3 三个 follow-up 全在打 CXO leading indicator 的工程实现(NLP vs 手工 / 跑批时长 / 映射表自动化);Turn 5/6/7 三个全在打 VECM 模型的统计取舍(ARDL vs Kalman / 数据口径 / 时滞 MAE)。**这种追问对一个已经在简历里写了"自己搭 pipeline"的强候选人毫无信息价值** — 她答得越漂亮,产品打越多类似题,等于在用候选人最强的肌肉群无限刷分。Persona "真盲点不在简历层面,而在 conviction 与周期阅历层面"产品零意识。

3. **同一根线最多追到第 3 层,且第 3 层经常退回到"团队痛点"水位**。典型如 skeleton Q3(项目): 4 → 5(模型权衡) → 6(**回到"团队最困扰的痛点是什么"**) → 7(时滞 MAE)。第 6 层是个倒车 — 候选人刚在第 5 层暴露了"模型样本期不包含 2008/2012-2014 杀估值",**第 6 层产品应该咬住这个 caveat 追问"那你在易方达模型实战部署期间,有没有遇到过模型预测和实际方向相反的季度、当时怎么解释",而不是把候选人拉回"团队痛点"的舒适区**。

4. **persona.anticipated_grey_areas 5 条撬点产品命中 0 条**:
   - "4 篇白酒里哪一篇 thesis 是你自己最先提出、mentor 一开始不同意但被你说服" — **零追问**
   - "抛开 mentor 和卖方共识,你 own 的非共识观点是哪个" — **零追问**
   - "你跟踪的票里有几只是你主动挑出来覆盖、最大回撤多少、怎么向 PM 解释" — **零追问**(turn 9 用假设题绕过)
   - "白酒模型样本期包不包含 2008/2012-2014 崩盘段" — **候选人在 turn 5 主动承认了,产品零跟进**
   - "拒掉中金 return offer 的真实原因是 carry/hours 还是对 IBD vs buy-side mindset 差异有清醒判断" — **零追问**(turn 0 候选人主动提了"拒中金",产品直接跳走问 CXO pipeline)

5. **追问对象偏差,turn 16-19 那条线特别明显**。skeleton Q5 是"为什么选嘉实",候选人讲到"嘉实白酒持仓和我的判断吻合"——产品 follow-up 17/18/19 全在追"持仓相关系数 / 数据延迟 vs 提前信号 / 你和基金经理沟通的例子"。**这条线本质是在测"你对嘉实的了解",但产品把它扯成了又一轮工程方法论展示** — 候选人借机把自己的研究框架又讲了 3 遍。一个有经验的面试官在 turn 16 之后会问的是:"你刚说嘉实研究文化你认同,具体哪一只嘉实在管的产品 / 哪一位嘉实基金经理的公开发言让你感到这种 alignment,引用一句具体的话给我听" — 这是真正区分"做过功课 vs 套话"的问法,产品没问。

### 跟 SAIF 老师说的话(产品交付角度)

老师,这次跑下来我直说:**产品现在的问题质量,只够给中等候选人(简历 6-7 分)做下限筛查,给 perfect-resume 的强候选人(8.5-9 分)用,等于面试官陪着候选人走完一遍流水线 — 没扎到任何能区分"流程齐全的优等生"和"未来能成为有声音的研究员"的轴**。

具体三点给开发参考:

**第一,skeleton 必须分 tier**。这位顾同学是 SAIF 学生池里典型的"流程齐全 + tier-1 简历"画像,首席面试官筛人的核心动作不是测她"会不会做研究"——她当然会——而是测她"那些漂亮的 thesis 到底是不是她的"。强候选人的骨架第 2 / 第 3 题必须替换成"你 own 的非共识观点 + 周期阅历"这两条专测 thesis 原创权属和下跌纪律的题。Persona 文件里 `student_tier=strong` 这个字段产品没有用上,白白浪费。

**第二,follow-up 调度逻辑严重偏工程。** 候选人在 turn 4/8/12 自己说了三次"mentor 指导下"、"在 mentor 的研究框架下"、"我把决策权留给了基金经理"——这是教科书级别的 conviction 弱信号,产品没有任何 trigger 顶上去。建议在 follow-up picker 里加一组"mentor 依赖词触发":检测到"mentor 指导 / mentor 给框架 / mentor 的判断更审慎 / 我的覆盖框架是从 mentor 延伸"这类短语,必须 deterministic 跳到"那这个 thesis 里有哪一部分是你最先提出 mentor 一开始反对的"。

**第三,产品现在打分体系也在放水**。turn 19 那一答(候选人主动承认"和 mentor 有分歧、最终 mentor 更审慎、分歧不大")在我这种实战标尺下应该是 50-55 分(暴露了 thesis 完全跟随 mentor),产品给了 72。如果让顾同学看这份成绩单,她会以为自己已经准备好嘉实首席面了,实际现场她大概率在一面通过、二面被首席凉——而且事后归因为"今天发挥不好",不会意识到根上少了"先 own 1-2 只票跑 6 个月"那个动作。**产品的可证伪反馈承诺,在这种强候选人 case 上没兑现。这是 SAIF 试点要给到学生的"看得见的反馈"最关键的一类样本,优先级建议拉满。**

### 跟 SAIF 老师说的话

老师, 如果顾承翊 (复旦本 + 光华硕 + 中金 + 易方达 + 高瓴这个 99 分配对的 strong 画像) 拿着这份反馈去准备嘉实二面, 她会得到的是: **"我整场平均 76.5, 系统给了我 4 个 90+ 的高分时刻, 我在 conviction / 周期阅历两个维度上 0 处 miss" — 也就是说, 系统在告诉她: 你已经 ready 了**。

这是这一轮 SAIF 试点里我最担心的一种失败模式: **学生越强、简历越漂亮、表达越流畅, 产品越容易被她骗, 越会给她错误的"你已经 ready"的信号, 越会让她带着虚高的自信进 panel — 而嘉实首席 5 分钟就能 demolish 这种 strong-on-paper / zero-conviction 的画像**, 学生事后会把失败归因为"那天发挥不好", 实际上是产品在 prep 阶段没刺破她的 illusion。

具体说四点:

1. **"漂亮 ≠ 有 view" 的识别完全失败**。Persona 的核心论点 — "她讲得清楚的是 mentor 的 thesis, 不是她 own 的" — 学生在 6 个 turn 里自己说出口了 (turn 1 / 4 / 8 / 10 / 12 / 13 / 19 都明文出现"mentor 给框架"), 产品 0 turn 把它转化成 miss, 反而 4 处把这种自爆当成 bonus "批判性反思 / 坦诚经历空白 / 将取舍与自我认知挂钩"。这是反馈系统最危险的反向校准: **诚实承认弱点的话术被当成了能力强**。

2. **C' 个性化命中率从 mid scenario 的 12.5% 退化到 strong scenario 的 0%**。19 条 memory, 0 条被精确引用。原因不是 LLM "没看到 memory", 而是当答案本身已经足够丰满, LLM scoring 没有动力去"用 chat memory 穿透答案"。这跟 mid scenario 暴露的问题是同一个根: **C' directive 在 prompt 层"鼓励引用", 但没有"必须 per-memory 判断相关性"的硬约束**, 学生越弱 LLM 越愿意去找 memory 凑, 学生越强 LLM 越懒得找。

3. **平均 76.5 是严重高估**。真实头部公募一面对这个画像的均分会在 65-68 — 不是因为她不够好, 是因为头部公募在 strong-on-paper 池里的淘汰逻辑是"找差异化 conviction", 不是"看流程是否齐全"。产品给到 76.5 会让学生形成"我比同辈应届有优势"的错觉, 实际嘉实 2027 届校招池里跟她平起平坐的 (清北复交 + 中金/中信/高盛 + 易方达/华夏) 至少 20 个, 真正区分她和这 20 个的不是 leading indicator pipeline (人人都有), 是有没有一个 own 的非共识 view (她没有, 但产品没告诉她她没有)。

4. **mid 和 strong 两个画像的反馈失败模式是完全相反的, 但都通向同一个产品缺陷**。Mid 画像 (林婉清) 反馈过度扣分 + 标签化 — 让学生觉得"我哪都不行";Strong 画像 (顾承翊) 反馈过度加分 + 把自爆当亮点 — 让学生觉得"我已经 ready"。两个方向都偏离了"真实头部公募面试官会怎么评" — 真实面试官对林婉清会发现"她有 1-2 个 punchy 的诚实瞬间值得保留", 对顾承翊会发现"她流程齐全但 0 个非共识观点, 是经典的 strong-on-paper 失败 candidate"。**产品当前的 scoring 系统对 conviction / 自有观点 / 周期阅历这三个**维度**没有专门的 detector**, hits/misses 标签集里没有"thesis 借自他人""周期阅历单薄""把执行能力包装成判断能力"这一组 anti-pattern。

**建议** (按优先级):

- **P0**: 在 ScoringPersonalizationDirective 里硬加一条 anti-pattern detector: 如果学生答案里出现 "mentor 给框架 / 在...指导下 / 是组里安排的 / 我负责数据和叙事" 这类短语, **必须**生成一条 personalized miss 指出"thesis ownership 边界未澄清"。同样, 出现"没有真实经历过 / 经历空白 / 没经历过下行" 这类短语**必须**生成 miss "周期阅历单薄, 在 panel 面前需要给替代证据" — 而不是当 bonus。
- **P0**: 给 "缺量化结果" / "缺关键取舍" / "未递球" 这三个高频泛标签加 question-type gate (反思题 / 方法论题 / 反问题禁用), 跟 mid scenario 同款问题 — 这是上一份 reviewer 已经提过的, 还没改。
- **P1**: C' directive 升级为"per-memory relevance scan": 对每条 chat memory 单独跑一次"这题是否相关"的判断, 相关则**必须**在 hit/miss 里点名引用 memory 的实体关键词 (而不是泛说"联用经历"), 不相关则不强行套。这条改完 mid scenario 也会受益。
- **P2**: 引入 "strong-on-paper trap detector" — 当学生 hit 中出现 "结构清晰 + 颗粒度恰当 + 行业认知深"3 个标签同时出现且 overall > 80 时, **必须**额外产出一条 manager-perspective 评语 "这是 strong-on-paper 答案, 流程齐全但是否有 own 的判断需要在...维度追问"。否则产品会一直被强候选人的丰满叙事骗。

最后一句直说: 这份 transcript 如果让嘉实股票投资部首席盲读 (我自己是公募背景, 我清楚他们的画风), 会在 turn 4 / turn 13 / turn 18 三个点直接给"形似而神不至"的评语, 整场最后均分会在 65-68; **产品给到 76.5 + 4 个 90+ 高光时刻, 跟首席的真实评价偏差 8-10 分**。这个偏差对 strong 学生是危险的 — 中等学生被压低分会更努力准备, 强学生被高估会带着假信心进 panel, 失败成本更高。

### 顾承翊的 5 条 takeaway (回去复盘她能带走什么)

> **判定标准**:这 5 条必须是"下一次面试 / 6 个月内的可执行训练动作",不是"我今天答得不错 / 我可以补一些量化"。

1. **"我必须自己 own 1 只票 6 个月,产生 1 个非共识 view"**(教学最希望她带走的)→ **她带不走**。产品全程没有指向这个方向,t20 她自己提"我最需要训练独立判断"但产品没接,她复盘时会归因为"我表达没问题,只是缺面试机会"。

2. **"我覆盖的票里只跟过反弹 / 横盘,没有下行案例,这是一个必须在面试前补的故事"** → **能带走**。t8 / t11 / t9 三次场景化的诚实自白会让她记住"下次面试官问下跌我怎么答",但她大概率会去**编一个故事**而不是去**主动覆盖一只下跌的票**——因为产品没明确告诉她"补的方式是去 own 一只票",而不是"准备一个话术"。

3. **"我对嘉实的'吻合'判断在 t17 被问崩了,讲公司故事时不要用没数据的'吻合'类强词"** → **能带走**。这是本场对她最直接的可执行反馈,t17 评分 55 是全场最低,她会记住"讲行业认同时不要用相关系数包装定性观察"。教学价值在,但层次很浅。

4. **"我答开放型 / conviction 题时会下意识切回'框架+案例'模式,这是 sell-side 训练的副作用"** → **她带不走**。persona.personality 里明确这一点,t13 / t18 都暴露了,但产品没有任何评分维度或反馈指向"你的结构化反而在伤你",她复盘时还会自我表扬"我答题非常结构化"。

5. **"我在 t13 / t19 主动承认了 mentor 依赖,这是真问题不是谦虚"** → **她带不走**。这两次自白如果有产品在下一题接上"那我们聊聊你最近 3 个月有没有一个 idea 是你跟 mentor 拍桌子坚持的",可以变成 takeaway;但产品没接,她回头看 transcript 会觉得"我那段反思讲得真诚,加分项",而不是"这是我的核心 gap"。

**结论**:5 条里只有 2 条 (#2 / #3) 能真带走,且都偏战术层。真正能改变她准备方式的战略级 takeaway (#1 / #4 / #5) 全没传递成功。**对强候选人的有效 takeaway 产出率 = 2/5 = 40%**。
