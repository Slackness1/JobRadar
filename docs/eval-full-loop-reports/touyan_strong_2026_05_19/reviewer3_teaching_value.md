# Reviewer 3 · 教学价值评估 — 顾承翊 (strong / 二级买方·基本面 / 嘉实行研)

> **角色定位**：SAIF 教学顾问视角。本场学生 persona 已属"流程齐全、笔头硬、表达成熟"的 top-tier 校招候选,简历分约 90 分。教学难度 = 把她从 80 分拉到 90+,不是把她从 50 拉到 70。**不给鼓励分**。

---

## 总评

**总分 58 / 100 · 定调:"产品成功撬开了 1 个核心盲点的边角(经历单薄已被学生自己说出来),但对 persona 真正最致命的 BS-1(conviction 借的) 与 BS-3(把流程齐全误认为天花板)几乎完全没碰到。强候选人这场只学到'我表达能力很强但缺一个 down-cycle 案例'这种半深的反馈,带不走'我必须在面试前主动 own 1 只票'这种可执行 next step。整场体感像是一位高质量学生陪产品打了一场漂亮的面经,但产品没有承担起'敲醒她'的教学责任。"**

强候选人这种学生用一次产品的合理教学增益应该是:产品逼出 1-2 条她自己复盘不会看到的盲点,并给出 6 个月可验证的训练动作。本场只完成了前半的边角,后半完全缺位。

## 顾承翊的 5 条 takeaway (回去复盘她能带走什么)

> **判定标准**:这 5 条必须是"下一次面试 / 6 个月内的可执行训练动作",不是"我今天答得不错 / 我可以补一些量化"。

1. **"我必须自己 own 1 只票 6 个月,产生 1 个非共识 view"**(教学最希望她带走的)→ **她带不走**。产品全程没有指向这个方向,t20 她自己提"我最需要训练独立判断"但产品没接,她复盘时会归因为"我表达没问题,只是缺面试机会"。

2. **"我覆盖的票里只跟过反弹 / 横盘,没有下行案例,这是一个必须在面试前补的故事"** → **能带走**。t8 / t11 / t9 三次场景化的诚实自白会让她记住"下次面试官问下跌我怎么答",但她大概率会去**编一个故事**而不是去**主动覆盖一只下跌的票**——因为产品没明确告诉她"补的方式是去 own 一只票",而不是"准备一个话术"。

3. **"我对嘉实的'吻合'判断在 t17 被问崩了,讲公司故事时不要用没数据的'吻合'类强词"** → **能带走**。这是本场对她最直接的可执行反馈,t17 评分 55 是全场最低,她会记住"讲行业认同时不要用相关系数包装定性观察"。教学价值在,但层次很浅。

4. **"我答开放型 / conviction 题时会下意识切回'框架+案例'模式,这是 sell-side 训练的副作用"** → **她带不走**。persona.personality 里明确这一点,t13 / t18 都暴露了,但产品没有任何评分维度或反馈指向"你的结构化反而在伤你",她复盘时还会自我表扬"我答题非常结构化"。

5. **"我在 t13 / t19 主动承认了 mentor 依赖,这是真问题不是谦虚"** → **她带不走**。这两次自白如果有产品在下一题接上"那我们聊聊你最近 3 个月有没有一个 idea 是你跟 mentor 拍桌子坚持的",可以变成 takeaway;但产品没接,她回头看 transcript 会觉得"我那段反思讲得真诚,加分项",而不是"这是我的核心 gap"。

**结论**:5 条里只有 2 条 (#2 / #3) 能真带走,且都偏战术层。真正能改变她准备方式的战略级 takeaway (#1 / #4 / #5) 全没传递成功。**对强候选人的有效 takeaway 产出率 = 2/5 = 40%**。

## 跟 SAIF 老师说的话

老师好。本场是我们 full-loop 评测里第一个 strong 学生 (顾承翊,北大光华 + 中金 IBD + 易方达 8 个月,简历层面对嘉实行研接近 perfect match)。直接说结论:

**这种学生用一次产品能学到什么**

- 一次像样的全英文 / 中文混合的 22 轮面试体感复盘,题目密度和颗粒度比同辈 mock 高
- 1-2 条战术级反馈(讲公司认同时别用"吻合"这种没数据的强词 / 注意补一个下行周期案例)
- 一份完整 transcript,自己回头能看到自己在 conviction 类问题上的延宕(t13 三次"……")和切回安全话题的本能(t18 末段)

**学不到什么 — 这才是关键**

- **产品没有刺破她最核心的盲点**: 她离开这场面试时仍然相信"我准备充分了",而 persona 真实诊断是"她需要在面试前 6 个月主动 own 1 只票、形成自己 own 的 thesis、并 track 跑 3-6 个月"。这个 next step 在 22 轮里**一次都没有以可执行动作的形式传达给她**。
- **产品的反馈 rubric 不适配 strong 学生**: hits / misses 的 tag 体系(结构清晰 / 量化结果 / 行业认知深)是为 mid 及以下学生设计的,对她这种已经 80 分到位的学生,这些 tag 全是"维持",没有"突破"。她 t2 拿 92、t18 拿 90,但这两个高分对她接下来一年的成长帮助约等于零。
- **产品不会主动告诉她"你在 IBD vs buy-side 心智差异上没复盘清楚"**: persona.anticipated_grey_areas 第 5 条预设的撬开点,整场 0 次触发。她从中金拿了 return offer 拒掉了,产品没有任何题指向"你拒的真实原因和你对两种思维差异的理解是什么"。

**给老师的两点直白建议**

1. **如果学院想把产品作为 top 学生的训练工具**,目前的 question generator + score rubric 必须叠加一层 "**strong-mode**" — 检测到学生已经 hit 全部 mid 级 rubric 后,自动切换到"刺破型追问"模式 (你 own 的 view 是什么 / 你最近一次跟共识 disagree 是什么 / 你跟踪的票最大回撤是多少)。当前版本 strong 模式不存在。

2. **顾承翊这一类学生(SAIF MF 班里至少 15-20 个)的真实风险**:嘉实 / 易方达一面通过、二面被首席凉。本场产品的 score 76.5 平均分会让她以为自己"过线",但 persona 诊断的失败模式恰恰是"strong-on-paper 但 conviction 不足"。**建议老师在使用产品后,人工补一道线下追问** ("你 4 篇白酒报告里有没有一篇的核心 thesis 是你最先提出 mentor 反对后来被你说服的") — 这道题产品问不出来,但学院能问出来,且足以定位她真实的成长 gap。

我们承认这场对 strong 候选人产品没尽到教学责任。下个版本的撬开器是 P0。
