## 4. B 路径 — 评论被点名 (Comment-mentions)

**结果: 0 输出。**

LLM 分析 Pony 全部 203 条评论 + 子评论(5392 字符),没找到任何提及其他博主的内容。

**这本身是个有用信号:** Pony 在读者眼里**孤峰式权威**。读者评论几乎全是问个人情况(我能投这个岗么 / 双非本能上中信么),**没人拿 Pony 跟其他博主对比**。

**含义:** B 路径在 Pony 这种独立性强的博主身上失效;**A 路径已经够用**。
