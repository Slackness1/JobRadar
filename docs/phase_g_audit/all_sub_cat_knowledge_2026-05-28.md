#### 硬门槛 (hard_requirements)

- 国内外重点院校硕士在读,2027 年及以后毕业;消费/食品/财经背景或 CPA 通过者优先
- 至少 1 段消费行研实习(券商食品饮料/商社组优先),周 4 天起、累计 3-4 个月以上
- Wind/Excel/财务建模熟练,能独立完成数据整理 + 行业动态跟踪 + 深度报告撰写
- 简历需有 1 份完整的消费个股或子行业深度报告(白酒/调味品/化妆品/餐饮等)
- 对热门标的(泡泡、名创、奶茶、潮玩等)能讲清楚产品-渠道-供应链三段拆解

#### 加分项 (soft_signals)

- 需求洞察能力:能从消费者心智、复购、人群迁移等维度反推商业模式
- 草根调研习惯:门店走访 + 经销商访谈 + 业绩会跟听,而非只看券商报告
- 对爆品/渗透率/品类扩张三种范式有自己的判断,而非套模板
- 对兴业、华创、天风等新财富食饮团队的报告风格熟悉,知道行业话语权分布
- 理解卖方推票本质是销售+服务,愿意主动维护买方客户关系

#### 转岗路径 (transfer_paths)

- **卖方研究员·消费医药周期 → 行业研究员·消费** (难度 low): 中型券商食饮组直接跳一线公募消费组,行业框架完全复用,主要补买方推票视角
- **消费品产业(品牌/电商/咨询) → 行业研究员·消费** (难度 medium): 产业背景在新消费方向有优势,但需补财务建模与二级估值,优先走 PE 投后过渡
- **美元消费基金/嘉御资本类一级 → 行业研究员·消费** (难度 medium): 一级转二级历史可行,卡点是 200 亿市值标的深度 + 二级跟踪频率训练

#### 风险/排雷 (pitfalls)

- 消费组被吐槽是最无用的研究员,行业增速 5-10%,缺乏 AI/Robotaxi 类性感叙事
- 脱离平台与资源后个人价值有限,职业不安全感强,头部公募留用率年年走低
- 卖方食饮赛道供给过剩,新财富团队留用名额紧,中部券商常以无薪小黑工填岗

#### 面试样态 (interview_style)

流程一般为简历筛-笔试-业务面-终面。业务面重点考过往实习、SQL/Wind/Excel 熟练度、对宠物医美等细分行业认知、深度报告产出。推票面会就一只热门消费标的(泡泡、奶茶、白酒)给出价格 + 时点观点。

#### 硬门槛 (hard_requirements)

- 研究生及以上学历在校生,经济/金融/财务等相关专业优先
- 实习期 3 个月以上,长期实习优先;每周到岗 3 天起
- 通过基金从业资格,熟练掌握 Wind / Office 等工具
- 有券商投行、研究所、基金等对口实习经验优先(暑期/秋招要求很高)

#### 加分项 (soft_signals)

- 认真细致、责任心强,接受'宁慢勿错、返工成本更高'的中后台节奏
- 对产品/交易/风控/估值清算等中台岗位分工有清晰理解,而非把它当投研的退路
- 能讲清楚基金会计与企业会计区别等岗位 know-how
- 对 gap 经历有正当解释,沟通和控场能力达标(群面易考察)

#### 转岗路径 (transfer_paths)

- **应届校招 → 公募中后台(产品/交易/风控/基金会计/IT)** (难度 中等): 近年中后台投递热度反超投研,头部公募仍卡对口实习与院校
- **FOF/投研岗投递落选 → 同公司中后台** (难度 中等): 易方达等头部公募 FOF 竞争过激,常被调剂到中后台岗
- **公募中后台风控 → 前台 FOF 研究/资产配置** (难度 高): 理论存在通道但博主实测难度大,跨前后台壁垒高
- **事务所/四大/券商投行实习 → 公募基金会计/运营** (难度 中等): 财务审计背景对基金会计有明显加分,需准备好交付物口径

#### 风险/排雷 (pitfalls)

- 把中后台当投研的兜底跳板,被问到岗位分工/职业规划时露馅
- REITs 等热门中后台岗常为无工资仅餐补的长期实习,需评估时间成本
- 中型公募 bonus 6-10 个月可观,但岗位天花板与流动性显著低于前台

#### 面试样态 (interview_style)

头部公募中后台面试三件事:岗位 know-how(基金会计 vs 企业会计、债股基风控差异、VaR、Brinson、业绩归因)、实习经历深挖(追问交付物如何落地)、稳定性与责任心(gap、'宁慢勿错')。南方基金有混岗群面 + 无领导讨论;IT 岗 Java 八股深挖底层。

- 复合背景(数据/统计/行业)有加分,能在路演材料与数据解读分歧场景里整合多方信息

#### 转岗路径 (transfer_paths)

- **量化研究员·公募/卖方 → 公募指数研究员** (难度 low): 因子/Barra/跟踪误差框架直接复用,主要补充指数编制规则与产品形态知识
- **公募权益行业研究员 → 公募指数研究员** (难度 medium): 易方达有暑期一志愿行研被调剂到指数研究的案例,行业框架可用但需补量化与编制方法

- **公募产品岗 → 公募指数研究员** (难度 high): 产品岗偏市场研究/法规细节,转研究需要补量化建模与因子工程,跨度较大

- 易方达暑期留用率低且周期只有 3 周-1 月,部分岗位线下时间冲突,投递前确认能否到岗

#### 硬门槛 (hard_requirements)

- 国内外重点高校经济/金融/数量经济硕士在读为主,毕业论文与货币政策、宏观经济相关是显性加分
- 至少 1 段券商宏观/策略组实习,头部所偏好十年 xcf 级团队或新财富宏观团队带教经历
- 熟练使用 Wind/CEIC + Stata/Python,能独立完成 CPI、社融、汇率等数据的拉取与建模
- 能给海关 PMI/CPI/社融第一时间出更新点评,并把宏观判断落到大类资产配置建议
- 上海/北京线下出勤 3 个月以上、每周 4 天起,英文央行报告(美联储/PBOC)可直接读写

#### 加分项 (soft_signals)

- 对中美博弈、出口链、人民币国际化等跨境宏观议题能搭出自己的分析框架
- 具备宏观判断→行业景气→资产配置的传导逻辑训练,推票/推板块能说清传导链路
- 能承受策略会、晨会、路演节奏,愿意周末加班赶月度/季度展望报告
- 对央行货币政策报告、政府工作报告、政治局会议公报有快速拆解的阅读习惯
- 对内幕信息红线与卖方合规边界有清晰认知,接触上市公司/政府机构数据时不踩线

#### 转岗路径 (transfer_paths)

- **公募/私募宏观研究员 → 卖方研究员·宏观策略** (难度 low): 买方宏观转卖方框架可直接复用,补路演与派点服务即可
- **央行/财政部/外管局体系研究岗 → 卖方研究员·宏观策略** (难度 medium): 政策理解深,但需补市场化报告写作与客户服务节奏
- **卖方行业研究员 → 卖方研究员·宏观策略** (难度 medium): 行业转总量需重建自上而下框架,适合中生代分析师
- **海外宏观经济学硕博应届 → 卖方研究员·宏观策略** (难度 medium): 海外框架强但需快速本土化,头部所对海归宏观持开放态度

#### 风险/排雷 (pitfalls)

- 做总量研究但说不清单一政策→行业景气→标的的传导路径,基金经理路演时被反驳
- 把策略报告写成事后小作文,缺乏前瞻性观点输出,派点会被持续下调
- AI 时代被动基金扩张+研究预算压缩,纯卖方宏观岗 HC 收缩,要预留向买方/产业端的退路

#### 面试样态 (interview_style)

中金宏观岗 10 问:中国核心矛盾+政策预判、美国对 A 股传导框架、CPI 领先指标、社融结构、英文概括央行报告;二面常考美联储降息与政策对症。国泰海通策略压自上而下框架、与首席观点相左如何独立验证、宏观→大类资产落地。固收实习走带教/组织/质控三轮。

#### 硬门槛 (hard_requirements)

#### 加分项 (soft_signals)

- 有二级市场研究实习经历者优先,研究所电面通常意味着已成功一半
- 撰写过行业深度报告或个股报告(如蒙牛/瓶装饮料等消费医药标的)的能体现产出能力
- 抗压能力强、能承受dirty work,行研是长期扎根一个行业的'业界博士'
- 对当前研究热点(硬科技/ESG/碳中和/创新药/老龄化)有自主观点和跟踪习惯
- 能向基金经理或投资者清晰路演,在观点与市场相左时敢于坚持发布

#### 转岗路径 (transfer_paths)

- **卖方研究员·消费医药周期 → 公募基金行业研究员** (难度 medium): 最常规去处,但通常要降薪且坐班打卡,从研究员重新做起
- **卖方研究员·消费医药周期 → 私募基金研究员** (难度 medium): 限制少薪酬可观,激励到位但稳定性弱
- **卖方研究员·消费医药周期 → 上市公司IR** (难度 easy): 压力小行业地位不错,消费医药公司IR对口度高
- **卖方研究员·消费医药周期 → 周期商品期货研究** (难度 easy): 新品种层出不穷,周期类研究员对口
- **卖方研究员·消费医药周期 → 战略咨询(BCG/MBB)** (难度 hard): 消费方向不景气时常见,JPM消费转BCG有先例

#### 风险/排雷 (pitfalls)

- 2024-2025券商整体降薪30%-60%,研究岗虽仍是高薪序列但奖金大幅缩水,新财富评选+降佣冲击双杀
- 分析覆盖盲区会被买方戳穿(如分析瓶装饮料不提瑞幸蜜雪冰城对现制茶饮的冲击)
- 广发等中型券商存在高管面'一票否决权',偏好理工/AI能力而非金融实习积累,业务与高管口味割裂

#### 面试样态 (interview_style)
