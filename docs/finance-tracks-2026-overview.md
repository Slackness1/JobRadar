# 金融高薪赛道 × 平台 × 岗位 总览 (SAIF 视角, 2026 alpha)

> 给 JobRadar 推荐引擎的"通识层"用 — 不到公司颗粒度,只到"赛道 → 平台类型 → 岗位类型"+ 质量 tag。

## TL;DR · SAIF 之前 5 个 track 的扩充

| 旧 track | 新 track 对应 | 评估 |
|---|---|---|
| 公募基金/研究 | 二级买方 → 顶级公募 → 主动行研 | ✓ 准 |
| 券商研究所 | 卖方研究 → 顶级券商 → 行研助理 | ✓ 准 |
| 二级市场买方 | 含 公募 + 大型私募 + 银行理财子 + 保险资管 (一锅炖) | **太宽,要拆** |
| 一级 PE | 一级市场 → 顶级 PE | ✓ 准,但**漏 IBD / FA / VC** |
| 量化研究 | 量化 → 顶级量化私募 → 中低频/中频研究员 | ✓ 准,但**漏海外做市 (Citadel/JaneStreet)** |

旧分类**漏掉**的香饽饽赛道:
- 投行 IBD (中金/中信/华泰 + GS/MS/JPM 中国/香港)
- 卖方 S&T (销售交易)
- 海外做市商 (Citadel Securities / Jane Street / Optiver / SIG)
- FA (青桐/华兴/汉能/光源)
- 国有大行**总行**投行 / FICC / 机构金融部
- 金融科技 (蚂蚁/微众/京东数科 — 金融底色 + 互联网 comp)
- MBB 金融服务组 (BCG/McKinsey FS — PE 跳板)
- 监管 + 体制内 (人行/证监/银保监 + 中投/丝路基金 — SAIF 二线学生会考虑)

## 低质量岗位红线 (任何平台都 ✗)

| 关键词 | 为啥差 |
|---|---|
| 柜员 / 大堂经理 / 营业厅 OP | 基层 + 销售压力 + 几乎不可逆 |
| 客户经理 (分行 / 支行) | 销售指标导向,投研专业训练接近零 |
| 保险代理人 / 寿险销售 | 类传销,无固定底薪 |
| 第三方理财销售 / 私募 FOF 销售 | 销售导向 |
| 渠道经理 / 渠道销售 (公募 / 私募) | 同上,XHS 双非硕案例频繁出现 |
| 财富管理顾问 / 投顾 (营业部) | 业务窄,职业天花板低 |
| 综合岗 / 行政 / 后台 (任何机构) | 不接触投研业务 |
| 分行综合管培生 | 方向不定,大概率沉到支行营销 |
| 营业部经纪 / 卖方销售内勤 | 重销售轻业务 |
| 银行远程客户经理 / 客服 | 客服业务,几乎不算金融 |

## 判断口诀 (给推荐引擎用)

**SAIF 学生选岗三问 — 全 yes = 香饽饽,全 no = 低质量**

1. **buy-side / 前台**? (是 → 加分; 后台 / 销售 → 扣分)
2. **顶级品牌**? (top-tier 公募/私募 + 头部投行 → 加分; 中小机构 → 一般)
3. **前 3 年能积累 transferable skill**? (research / modeling / dealing → 加分; KPI 跑销售指标 → 扣分)

| 三问得分 | 评级 |
|---|---|
| 3/3 | ★★★ |
| 2/3 | ★★ |
| 1/3 | ★ |
| 0/3 | ✗ |

## XHS 数据补充 (n=8 帖, keyword="金融校招赛道选择", 2026-05)

抓的 8 帖跟我的赛道树高度吻合 (没新增赛道,但补 1 个维度):

- **新增维度: "金融 + 体制内"** — 一帖明确把求职拆成"市场化 vs 体制内"两条路。体制内含: 一行三会 / 国央企财务 / 大行总行管培。SAIF **二线学生**(非清北复交)很多选体制内保底。已加入 §6 监管机构 + 体制内。
- **验证"渠道销售/客户经理"是低质量主流**: 双非硕复盘帖列了 20+ 进面公司,**多数是"渠道经理 / 客户经理 / 营销岗"**(平安寿险 / 上海银行客户经理 / 招行远程客户经理 / 工行深圳分行营销 / 北京银行渠道 / 鹏华基金渠道销售...)。**这是低质量岗位的高频面相**, SAIF 学生应自动跳过这类 keyword。
- **金融科技细分**: 一帖明确列了金融科技子赛道 — 跨境支付 / 合规 / 量化 / 留学生导向。已并入 §7。
- **券商培训计划是 SAIF 同学常见纠结点**: 中信证券 (title 强) vs 广发证券 (培养体系强,总部半年培训) — 验证 §1 §4 顶级券商作为推荐目标合理。

XHS 数据**没**反过来推翻我的树。这是树的健康信号 — SAIF 视角的赛道分类跟应届生群体的真实纠结一致。

## 给 JobRadar 推荐引擎的接入建议

1. **第一层 "track" 分类用本文档的 §1-§8 八大赛道**。比之前 5 个 track 多 3 个 (S&T 拆出 / 监管+体制内 / 金科)。
2. **第二层 "平台 tier" 分级用 ★ 系统**。一个 JD 命中 "顶级公募 + 行研" → ★★★;命中 "分行 + 客户经理" → ✗。
3. **关键词黑名单**用 §"低质量岗位红线" 那张表。任何 JD 标题含"柜员 / 客户经理 / 渠道 / 营销 / 大堂经理 / 客服" → 自动评级 ✗。
4. **校招 vs 社招分流**: 校招 SAIF 学生应被推 ★★ 及以上;★ 仅在用户主动放宽时推; ✗ 永远不推。
5. **三问引擎**: recommendation.py 加一个 `_is_low_quality_role(job_title)` 函数, 命中 §"红线" keyword 直接 final_score -50 + tier='有差距'。
