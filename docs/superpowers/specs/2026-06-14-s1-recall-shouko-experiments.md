# S1 召回收口 — Ablation 实验结论(2026-06-14)

> 在 72-query eval set 上跑了 5 个收口变体(不重新调判官,只对已判分候选重排/过滤)+ offtrack@5/10/20 指标。
> 目标:把 dense 的跑偏率压到可上线,且不牺牲召回质量。

## 变体对照(全体 72 query)

| 变体 | nDCG@10 | Recall@20 | off@5 | off@10 | off@20 |
|---|---|---|---|---|---|
| baseline(现状) | 0.238 | 24.9% | 0% | 0% | 0% |
| **dense** | **0.641** | **58.1%** | 9.4% | 13.3% | 17.7% |
| dense+cosine下限 | 0.641 | 58.1% | 9.4% | 13.3% | 17.7% |
| dense+职能关键词guard | 0.643 | 58.1% | 9.2% | 13.1% | 17.7% |
| dense+sub_cat软降权 | 0.656 | 58.1% | 8.9% | 12.1% | 17.7% |
| 补位(baseline+dense) | 0.349 | 44.4% | 0.8% | 1.4% | 4.0% |
| 覆盖自适应 | 0.361 | 44.6% | 1.1% | 1.4% | 4.0% |

## 五个变体逐一证伪/证实

1. **cosine 下限 = 无效。** 金融跑偏岗 cosine 均值 0.626、相关岗 0.645,**分布几乎完全重叠**(都在 0.49~0.81)。跑偏岗就是高相似度的语义近邻,任何阈值按比例砍掉两边,分不开。
2. **职能关键词 guard = 几乎无效**(off@5 12.1→11.7%)。诊断发现:金融跑偏岗**大多标题写着"研究员"**——是"隔壁专业的研究岗"(主观基本面学生被推量化研究/FOF/固收研究),不是销售/运营。关键词抓不到。
3. **sub_cat 软降权 = 小幅有效**(nDCG +0.015,internet off@5 4.2→3.3%)。能降"enrich 到错研究桶"的那批,但抓不到 NULL 的跑偏岗。**印证了"sub_cat 当软先验信号"有价值,但单靠它不够。**
4. **补位 / 覆盖自适应 = 跑偏压到 4% 但 nDCG 腰斩**(0.64→0.35)。因为它 leading 弱 baseline(尤其互联网 baseline nDCG 才 0.065),把 dense 的大胜丢了。且"按 baseline 条数路由"会把"返回 20 条垃圾"误判成"覆盖够"。**不可取。**

## 两个比变体更重要的反转

**反转 A — off@20 这个验收标准本身偏严,off@5 才是学生真感受。**
dense 总体 off@5 只有 **9.4%**(互联网 **4.2%,已达标**),金融 12.1%。跑偏几乎全在 11~20 位的尾部。学生首屏看 top-5,体验远好于 off@20=17.7% 显示的。**建议把验收主指标从 off@20≤8% 改成 off@5≤8%**(更贴体验)。

**反转 B — 我们一直在"裸召回"上量跑偏,但线上召回后面还有一道 LLM 精排。**
生产链路是:召回 → 规则打分 → **Pro LLM 逐岗精排(top-N)** → 展示。dense 召回那 19.6% 跑偏,**是精排的输入,不是用户的输出**——精排本职就是给每个岗打相关分、把不对口的压下去。**我们等于在"没经过精排"的半成品上判跑偏,对整条管线不公平。** 真正该问的是:**dense 召回 → 跑现有精排之后,off@5 还剩多少。**

## 结论 & 下一步

- **没有任何单一召回侧技巧能在不腰斩 nDCG 的前提下把 off@20 压到 8%**——因为跑偏是高 cosine、常是相邻研究岗或 NULL,召回侧分不开。
- **真正的精准度防线是召回后面的那道 LLM 精排**(已存在),外加**分层展示**(强匹配/可迁移/探索)把相邻可迁移岗honestly 单列,而不是当垃圾删。
- **召回侧定方案:dense + sub_cat 软降权**(免费拿 +0.015 nDCG、降一点跑偏),互联网纯 dense 已达标。
- **下一个关键实验(实验 5,需你拍):** dense 召回 → 跑现有 Pro 精排 → 量 off@5。这是对整条管线的公平测试。成本:约 72 query × top-30 ≈ 2000+ 次 Pro 调用(与学生流量共用 OpenCode 额度,需错峰)。如果精排能把 off@5 压到 8% 内,**S1 dense 召回即可上线,精排当精准度防线**,不必在召回侧硬抠。
