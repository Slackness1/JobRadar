# 新手「一图看懂」向导面板 设计 (2026-06-04)

> 子项:面向 SAIF 学生的自助上手向导。降低"第一次进来不知道先干嘛"的摩擦。

## 1. 背景与目标

产品当前的学生主线是:首页 → 登录 → 选简历页 → 上传简历 → 确认页(赛道 + 细分方向 + 求职模式)→ 工作台(梯队骨架 / 推荐 / AI 简历助手 / 简历预览)→ 模拟面试。

新用户第一次进来,**不知道该先传简历还是先选赛道、工作台三块各是干嘛的**。本设计加一个轻量向导,用一条"四步看懂"的主线把整条产品链路讲清楚,让学生自己能走完全程。

**成功标准**:
- 新学生第一次登录后,无需他人指导即可看懂"先做什么、每一步的价值"。
- 向导不打扰老用户(看过一次后不再自动弹)。
- 任何时候能从常驻入口重新打开。
- 不依赖具体按钮位置 —— UI 还在打磨,向导改动后不易碎。

**非目标(YAGNI)**:
- 不做产品内分步浮层(coachmark)跟真实按钮紧耦合 —— UI 一改就要维护。
- 不做静态图片文件(PNG/SVG)—— 文字一改要重出图,手机看不清。
- 不做视频。
- 本版不配产品截图 —— 纯图标 + 文字,UI 打磨完再考虑加截图。
- 不做后端 / 数据库改动。

## 2. 形态决策(已与用户确认)

| 维度 | 决策 |
|---|---|
| 受众 | SAIF 学生,自助上手 |
| 形态 | 用网页搭的「一图看懂」面板(响应式、可随时改字、手机清晰、轻交互),以**弹窗**呈现 |
| 出现时机 | 首次登录自动弹一次(可关闭 / 不再提示)+ 首页和选简历页常驻「怎么用」入口 |
| 视觉 | 沿用现有 HiFi 陶土设计系统,`.hf` scope,不污染其它页面 |
| 截图 | 本版不配,纯图标 + 文字 |

**顺带价值**:首页的「怎么用」入口未登录也能点 —— 等于顺便给来访老师/新访客一个轻量产品讲解,无需额外做"演示版"。

## 3. 面板内容

**标题**:JobRadar 怎么用 · 四步看懂

| 步骤 | 标题 | 做什么(一句) | 对学生的价值(一句) |
|---|---|---|---|
| ① | 上传简历 | 传一份简历(PDF/Word),AI 自动读出教育 / 实习 / 项目 / 技能 | 不用填表,传完就开始 |
| ② | 选赛道 + 细分方向 | 挑想去的金融赛道,再勾二级细分(如"公募权益研究员"),AI 帮你预勾最像的 | 选得越准,推荐和打分越贴你 |
| ③ | 进工作台(核心) | 左=梯队骨架(目标公司按稳/匹配/冲刺分档+情报)· 中=AI 简历助手(按目标岗诊断+改写建议,不编数字)· 右=简历预览;外加真实岗位推荐 | 一屏看清"我能去哪 + 简历差在哪" |
| ④ | 模拟面试 + 反馈 | 针对某个岗位做模拟面试,AI 逐轮追问 + 给反馈 | 面试前先练一遍,拿到具体可改点 |

**底部**:
- 主按钮 **「立即开始 →」** → 跳到上传页 `/upload`。
- **「不再提示」** 勾选(勾上即写入"已看过"本地状态)。

**步骤 ③** 因为信息量大,面板里用一个小三栏排版(左/中/右),与工作台真实布局呼应,帮学生建立"工作台是三块"的心智。

## 4. 轻交互

- 鼠标悬停某一步 → 该步卡片高亮(陶土描边 / 微提升),并展开一句更细的补充说明。
- 纯前端 CSS / state,不调后端。
- 移动端无 hover,默认展开或可点击展开;不依赖 hover 才能看懂(hover 仅为增强)。

## 5. 触发与状态逻辑

- **"已看过"状态**:浏览器 `localStorage`,key `jobradar.onboarding.guideSeenV1`(带版本号,日后面板大改可 bump 版本重新弹一次)。
- **首次自动弹**:学生登录后落到选简历页(`/resume-copilot/sessions`)时,组件挂载检查该 key —— 未设置则自动打开面板。
- **关闭即标记**:点关闭 / 点「立即开始」/ 勾「不再提示」任一,都写入该 key,之后不再自动弹。
- **常驻入口**:首页(hero 顶栏)和选简历页头部各放一个「怎么用」按钮,点击直接打开面板(与是否看过无关)。
- 不写后端、不写数据库;状态纯客户端。账号换设备 / 清缓存会重新弹一次 —— 可接受。

## 6. 组件结构与边界

| 单元 | 职责 | 依赖 |
|---|---|---|
| `GuidePanel`(面板内容) | 渲染四步主线 + 底部按钮 + 轻交互;纯展示,无状态副作用 | HiFi primitives(`HFBtn` 等)、图标 `I.*` |
| `GuideModal`(弹窗壳) | 遮罩 + 居中容器 + 关闭;复用现有登录弹窗(`AuthModal`)的样式模式 | `GuidePanel` |
| `useGuideSeen`(本地状态钩子) | 读 / 写 `localStorage` 的"已看过"标记;给"是否自动弹"和"勾不再提示"用 | 无 |
| 「怎么用」入口按钮 | 放在 hero 顶栏 + 选简历页头部;点击 `open()` | `GuideModal` |
| 选简历页首登自动弹接线 | 挂载时若未看过则自动 `open()` | `useGuideSeen` |

- 全部在 `.hf` scope 内,样式不外溢到 `/interview/*`、workspace、admin。
- `GuidePanel` 可独立理解、独立测;改其内部排版不影响触发逻辑。

## 7. 验收

- `npm run lint` 0 error;`npm run build` 通过。
- 手动走查:
  1. 清掉 `localStorage` 该 key → 登录落选简历页 → **自动弹一次**。
  2. 关闭 / 勾"不再提示" → 刷新 → **不再自动弹**。
  3. 首页「怎么用」/ 选简历页「怎么用」→ 任何时候点都能打开。
  4. 首页未登录也能点开「怎么用」。
  5. 悬停某一步高亮 + 展开补充说明;移动端窄屏排版正常、四步可读。
- 设计系统隔离:打开向导时 `/interview`、workspace 调色不被影响。

## 8. 交付方式(分两段)

1. **独立 HTML 预览先行**:先产出一个自包含的静态 HTML(内联样式,无需起服务),放 `jobradar-sync/` 供本人直接在浏览器打开,确认面板观感 / 文案 / 排版。这是"做个 html"的直接产物,也是后续组件的视觉源。
2. **落成组件并集成**:观感确认后,把同一份设计落成 `.hf` scope 的 React 组件(`GuidePanel` + `GuideModal`),接上 §5 的触发逻辑(首登自动弹 + 常驻「怎么用」入口),进产品。
- 两段共用同一套视觉与文案;独立 HTML 是真实来源的镜像,改文案两边同步。

## 9. 上线

- 纯前端,沿用 `jobradar-vps-deploy` 标准流程(前端重 build)。
- 无 DB 迁移、无后端重启必要(只重启前端服务)。
