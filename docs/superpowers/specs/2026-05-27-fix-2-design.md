## 0. 复盘 — 为什么之前漏了这么多

3 个失误,按影响排:

1. **从未产出"全交互清单"** — 给 subagent 的 prompt 都是高层任务描述,没把设计 jsx 里**每个按钮 / 每个状态切换**逐项列出。Subagent 按高层描述做,自然漏细节。
2. **Subagent 的"简化清单"是 self-reported, 我没 cross-check** — Subagent 报告"简化了 X / Y / Z",但**它没意识到要做的东西不会出现在这个清单里**(unknown unknowns)。每次只看 lint+build 过就 commit。
3. **跨边界入口最易漏** — 比如 chat composer 底部 "Coach" pill 是 Chat 模块的 UI,但功能上是 Coach 模块的入口。subagent 实施 Coach (P1) 时没动 Chat 模块,这个入口就漏了。

**这次 Fix-2 流程改造:**
- 先 1:1 系统 audit 出**全交互清单**(已做,见第 1 节)
- 每个 PR 完成后**亲自 grep + 打开文件验证 onClick 真做什么**(不再单纯依赖 subagent self-report 或 audit ✅ 标记)
- 用户验收时给清晰 checklist 逐项打勾
