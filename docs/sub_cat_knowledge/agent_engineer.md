## 硬门槛

- 至少 1 个亲手做的 AI Agent 项目,简历能挂 demo 链接,面试要求投屏演示
- 掌握 Agent 核心范式:tool calling/多步推理/记忆管理/ReAct/Multi-Agent,熟主流框架
- RAG 工程链路能讲透:文档切割、chunk、embedding 选型、向量库、token 超限
- Prompt 工程懂 system prompt/few-shot/output format/hallucination control/上下文工程
- 懂大模型概念边界:Transformer/embedding/SFT vs RLHF/LoRA/KV Cache 应用场景

## 加分项

- 重度 Agent 用户:日常用 Claude Code/Cursor/Codex,能讲 coding agent 差异
- 刨根问底的工程师气质:Kimi Harness Team 等明确要求 '相信技术、习惯刨根问底',能从 bad case 反推底层原理
- 全栈能力:Agent 岗实际偏业务开发,简历最好有 1-2 个前后端项目,纯算法/Agent 项目堆叠反而扣分
- 把模型能力翻译成业务价值的能力:能讲清楚某 Agent 工作流帮 xx 业务节省多少人天/提升多少转化,而非堆技术名词
- 评估能力意识:面试会追问 '你这个 Agent 怎么评估好坏',懂 AgentBench/SWE-bench 等评估框架是显著加分项

## 转岗路径

- **后端/全栈开发 → Agent 工程师** (难度: low) — 工程能力直接复用,补做 2 段 RAG+Agent 项目,边干边学半年可拿大厂 offer (xhs 26 届后端转 Agent 真实案例)
- **纯算法 / 大模型预训练方向 → Agent 工程师** (难度: medium) — 算法岗卷顶会+学历,Agent 岗更看重工程落地;短板是产品 sense 和全栈工程,需补前后端项目
- **金融研究员/卖方分析师 (SAIF MF 学生原赛道) → Agent 工程师** (难度: high) — 工程门槛硬:需 CS/AI 背景或自学补全;建议先走 AI PM 路径,或瞄准金融垂直 Agent(蚂蚁百宝箱/券商投研 Agent)
- **传统 NLP / 搜推算法 → Agent 工程师** (难度: low) — 技术语言通顺,补 LangGraph/MCP/Agent 评估框架即可平迁;美团/百度搜推团队内部转 Agent 路径成熟

## 风险/排雷

- 警惕挂羊头卖狗肉的 Agent 岗:阿里校招 AI Agent 入职后核心做服务端/前端,只叠一点 Skill 研发;offer 前先问清楚业务真实占比
- Agent 知识更新快,门槛持续抬高:4 月投半个月算法岗 0 面试是常态,要持续追踪 MCP/Claude Skill/新框架,半年没动手就脱节
- 简历技术点必被深挖:写 RAG 要能答 chunk+向量库,写 Agent 要能答 tool 设计,虚标必扣分
