## 硬门槛 (hard_requirements)

1. 985/211 或 QS50 院校,理工科/金融工程/数学/计算机硕士及以上,头部岗位明确偏好 PhD
2. 扎实的统计与概率基础,熟练 Python+numpy,头部量化普遍要 C++ 或工程化能力
3. 至少 1 段头部量化私募或公募量化部实习,做过完整因子挖掘/回测闭环
4. 对 IC、rank IC、换手率、Sharpe/Calmar、过拟合等核心概念能在面试现场推导

## 加分项 (soft_signals)

- 数学建模/ACM/Kaggle/顶会论文等可量化的竞赛与科研产出
- 对 A 股市场结构有具体洞察(如大小盘风格风险、对冲品种缺口)而非泛泛而谈
- 有自己跑过实盘或公开 GitHub 策略代码,能讲清单一因子的失效原因
- 中低频股票方向实习经历(明汯/灵均面试官明确询问)

## 转岗路径 (transfer_paths)

- **卖方研究员·TMT → 量化研究员·中频** (难度: high) — 需补统计建模+编程,通常要再加一段量化私募实习才有面试机会
- **量化开发QD → 量化研究员·中频** (难度: medium) — 工程底子够,但要把因子构建/回测方法论补成研究语言
- **公募指数研究员 → 量化研究员·中频** (难度: medium) — 对指数与组合优化熟,转中频私募需补 alpha 因子和换手率思维

## 排雷 (pitfalls)

- 把通用机器学习简历直接投头部量化,不展示金融数据/因子细节会一面被刷
- 不准备 coding 题(九坤等头部会现场写题),思维定势认为只考因子
- 实习 offer 转正率不透明就 all-in,挤掉其他秋招面试窗口

## 面试样态 (interview_style)

头部量化以技术面+因子头脑风暴为主:1)简历项目深挖,追问时间复杂度、尾部样本处理;2)概念硬题如 IC/rank IC 区别、Sharpe 对低胜率高赔率策略失效、市场中性与股指期货匹配;3)九坤等会突然加 coding,明汯偏因子头脑风暴。氛围轻松但题目密度极高。

## 薪酬信号 (compensation_signal)

头部量化策略研究员校招总包约 150 万/年(verbatim Post 18);灵均资深 CTA 研究员月薪 30-60k

## 职业轨迹 (career_trajectory)

1 年内:跟资深研究员做因子挖掘+回测,产出可上线的小因子;3 年:独立负责一个策略子线(如中频量价或基本面因子组),管理实盘部分敞口;5 年:晋升资深研究员或基金经理助理,带 1-2 人小组或独立管理产品,头部机构核心团队从业普遍 9 年以上。
