## 硬门槛

- 重点大学本硕应届理工科,计算机/软件工程相关,顶尖院校或 ACM/奥赛获奖者优先

- ACM/ICPC/NOI/Kaggle 等编程竞赛获奖,或开源项目可展示

## 转岗路径

- **互联网后端工程师 → 量化开发QD** (难度: medium) — C++/Go 工程能力可复用,需补金融数据一致性、低延迟调优、回测框架基础
- **券商金融科技岗 → 量化开发QD** (难度: medium) — 有交易系统背景加分,补强算法竞赛功底和 Linux 性能分析
- **AI Infra/HPC 工程师 → 量化开发QD** (难度: low) — CUDA、算子优化、训练框架经验直接对口九坤等 AI Infra 方向
- **量化开发QD → 量化研究员·中频** (难度: high) — 需补统计建模、因子构建方法论,通常要再加一段研究侧实习

## 风险/排雷

- 简历堆 Python 项目却没有 C++/Linux 系统级深度,头部 QD 一面会被刷
- 面试只准备算法题不准备底层(Profiling、Bank Conflict、Shared Memory),九坤等会深挖到讲不下去
- 把简历项目写得很泛,面试官逐行 review 代码时答不出实现细节

## 面试样态

头部量化 QD 以底层技术深挖为主:1)简历逐行 review,打开代码现场看实现;2)手撕 GEMM Naive/Shared Memory、O(1) 栈最小值、200 亿 long 数据等大题;3)考察 CUDA、算子融合、Nsight 分析、限流/容错;九坤允许查 AI/谷歌,看实际工作能力。
